# DeboFlow Frontend

Frontend for the Debo fullstack project management application.

## Tech Stack

- React
- Vite
- Tailwind CSS
- Axios
- React Router DOM
- DnD Kit

## Features

- Authentication UI
- Dashboard
- Project management
- Task management
- Kanban board
- Drag and drop tasks
- Search functionality
- Responsive UI
- Profile editing
